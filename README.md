# CT Brain Trainer

تطبيق ويب تعليمي للتدريب على تشخيص صور CT الدماغ، يشتغل بالكامل في المتصفح.

> **تنبيه:** هذا التطبيق للتعليم والبحث فقط. ليس أداة تشخيص سريري، ولا يُستخدم لاتخاذ قرارات تتعلق بعلاج مريض. أي صورة طبية لازم تكون مجهولة الهوية ومن مصدر مرخّص للاستخدام.

## المرحلة الأولى
- نزيف داخل الجمجمة: Epidural، Subdural، Subarachnoid، Intraparenchymal، Intraventricular

## كيف تشتغل
1. تشوف صورة CT axial بنافذة الدماغ.
2. تختار التشخيص.
3. تشوف الإجابة الصحيحة مع الشرح.
4. نتيجتك بتتسجل على جهازك فقط (localStorage).

## المصادر
- RSNA Intracranial Hemorrhage Dataset (Kaggle)
- CQ500 (Qure.ai)
- The Cancer Imaging Archive (TCIA)
